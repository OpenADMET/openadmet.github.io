{{/* Returns the most recent blog post as a dict: title, url, date, summary. Posts come from Ghost via content/blog/_content.gotmpl, which fails the build if Ghost is unreachable, so there is always a newest post here. The summary comes from the post's Excerpt field in the Ghost editor. If no excerpt is set, Ghost falls back to the opening sentences of the post, which reads poorly on a card — so set the Excerpt when publishing. */}} {{ $latest := index (site.GetPage "/blog").Pages.ByDate.Reverse 0 }} {{ return dict "title" $latest.Title "url" ($latest.Params.external | default $latest.RelPermalink) "date" ($latest.Date.Format "January 2, 2006") "summary" ($latest.Params.excerpt | truncate 200) }}
